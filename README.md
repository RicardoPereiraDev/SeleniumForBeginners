# Selenium for Beginners

This repository contains my learning project and exercises while
following the Udemy course **Selenium for Beginners**.

## About the Course

The goal of this course is to build a solid foundation in Selenium
WebDriver automation using Java.

Throughout the course, I am learning how to create, structure and
execute automated UI tests using Selenium and related testing tools.

## Technologies

- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA
- Git
- GitHub
- Selenium Grid

## Topics I'm Learning

- Selenium WebDriver fundamentals
- WebDriver and browser automation
- Locating web elements
- WebElement interactions
- XPath and CSS selectors
- Test automation with TestNG
- Test annotations
- Assertions
- Test groups
- Test parameters
- Page Object Model
- Page classes
- Test framework structure
- Browser configuration
- Selenium Grid
- RemoteWebDriver
- Running tests remotely
- Cross-browser testing
